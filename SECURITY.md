# Security policy

dotonce stores what your AI agent saw and said, and adds text to its prompts, so a bug that leaks memory between projects, sends data anywhere, or lets a downloaded repo add rules without your approval matters. Every report gets read and answered.

## Supported versions

| Version | Supported |
|---|---|
| 0.x | Yes |
| Older | No |

## Reporting a vulnerability

Please don't report a security issue in a public issue or pull request. Open the [Security tab](https://github.com/dotbrainhq/dotonce/security) of this repo and select "Report a vulnerability". Only you and the maintainers can see the report.

A good report has the version, the steps to reproduce it, what an attacker gains, and a proof of concept if you have one.

## What happens next

- Within 3 business days: we confirm we got your report.
- Within 14 days of confirming the issue: we ship a fix or send you a plan with a date for it.

Please give us the chance to release the fix before you publish anything about the issue.
